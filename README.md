# 🛂 منصة التأشيرات

منظومة لمتابعة متطلبات التقديم على التأشيرة — الزبون يسجل ويجاوب على استبيان المتطلبات (هل عندك؟ / هل مترجمة؟)، والأدمن يشوف جميع الزبائن ونواقص كل واحد.

## التقنيات

| الجزء | التقنية |
|---|---|
| الواجهة | React + Vite (عربي RTL) |
| الخادم | Node.js + Express |
| قاعدة البيانات | PostgreSQL (منفذ **5433**) |
| المصادقة | JWT + bcrypt |

## التشغيل

```bash
./تشغيل.sh
```

ثم افتح: **http://localhost:5173**

أو يدوياً:

```bash
# 1) قاعدة البيانات
/opt/homebrew/opt/postgresql@14/bin/pg_ctl -D /opt/homebrew/var/postgresql@14 -o "-p 5433" -l /opt/homebrew/var/log/postgresql@14-5433.log start

# 2) الخادم
cd server && npm start

# 3) الواجهة (نافذة طرفية ثانية)
cd client && npm run dev
```

> ملاحظة: نستخدم المنفذ 5433 لأن على جهازك خادم Postgres آخر شاغل المنفذ 5432 ويطلب كلمة سر.

|---|---|---|
| أدمن | `0910000000` | `admin123` ⚠️ غيّرها |
| زبون تجريبي | `0921234567` | `test123` |

## المتطلبات في المنظومة

1. تأمين صحي ساري
2. حجز طيران مبدئي (ذهاب وعودة) — بعد أسبوعين من موعد التقديم
3. حجز فندقي مبدئي — مطابق للتذاكر والسعر مذكور
4. رسالة من جهة العمل (مرتب/صفة/اسم/ختم/توقيع) — **مترجمة**
5. كشف حساب آخر 6 شهور — ختم حي
6. شهادة وضع عائلي بتاريخ جديد — **مترجمة**
7. صورة شخصية بمواصفات التأشيرة
8. كفالة مالية من محرر عقود — **مترجمة** (حسب الحالة: لمن لا يملك إفادة عمل وكشف حساب)
9. أوراق الشركة: سجل تجاري + رخصة + إثبات قيد — **مترجمة** (حسب الحالة)
10. النسخة الأصلية للمستندات يوم الموعد

لتعديل قائمة المتطلبات: عدّل `server/src/setup.js` ثم شغّل:

```bash
cd server && npm run setup-db
```

(آمن — يحدّث القائمة بدون مسح بيانات الزبائن)

## هيكل المشروع

```

├── server/          # Express API
│   ├── .env         # DATABASE_URL, JWT_SECRET, PORT

│       ├── index.js     # نقاط النهاية (auth, checklist, admin)
│       ├── setup.js     # إنشاء الجداول + المتطلبات + حساب الأدمن
│       ├── schema.sql   # هيكل الجداول
│       └── db.js        # اتصال Postgres
└── client/          # واجهة React
    └── src/
        ├── App.jsx      # الدخول + قائمة الزبون + لوحة الأدمن
        ├── api.js       # استدعاءات API مع التوكن
        └── styles.css   # تصميم RTL
```
